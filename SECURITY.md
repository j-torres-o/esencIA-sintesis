# Política de Seguridad para esencIA

## 🛡️ Compromiso de Seguridad

En **esencIA**, nos tomamos muy en serio la privacidad de la información y la seguridad de los usuarios. Dado que la aplicación está diseñada para operar **100% de forma local** (usando Ollama y Whisper locales), los datos del usuario nunca deben enviarse a servidores externos sin consentimiento explícito.

---

## 🔒 Reportar una Vulnerabilidad

Si descubres un problema de seguridad o vulnerabilidad en **esencIA**:

1. **NO abrís un issue público** en GitHub.
2. Contacta directamente a los mantenedores del proyecto enviando un correo con los detalles del reporte.
3. Incluye la siguiente información:
   - Descripción detallada del problema o vulnerabilidad.
   - Pasos para reproducir el fallo.
   - Posible impacto de seguridad.
